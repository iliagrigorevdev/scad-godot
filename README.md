# 🎮 scad-godot

**Playable 3D Godot 4 games where every asset, script, and scene is generated from pure code using OpenSCAD and AI.**

`scad-godot` is a showcase and hub of interactive, browser-playable Godot 4 games built with a **code-first asset pipeline**. Instead of relying on traditional binary 3D models (FBX/OBJ), all 3D assets are written as parametric OpenSCAD (`.scad`) scripts and compiled into web-ready glTF/GLB binaries on the fly via the [`scad-gltf`](https://github.com/iliagrigorevdev/scad-gltf) WebAssembly engine.

**🕹️ Play the Live Web Demos:** [https://iliagrigorevdev.github.io/scad-godot/](https://iliagrigorevdev.github.io/scad-godot/)
