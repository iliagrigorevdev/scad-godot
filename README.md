# 🎮 scad-godot

**Playable 3D Godot 4 games where every 3D asset, script, and scene is generated from pure code using OpenSCAD and AI.**

This repository hosts the live WebAssembly / WebGL builds of procedural Godot 4 games generated by the [`scad-godot`](https://github.com/iliagrigorevdev/scad-gltf) pipeline.

Instead of traditional 3D asset formats (FBX/OBJ/Blender), every model in these games was defined procedurally in code as an OpenSCAD (`.scad`) script and converted to glTF using the [`scad-gltf`](https://github.com/iliagrigorevdev/scad-gltf) compiler.

**🕹️ Play the Games in Your Browser:**
👉 **[https://iliagrigorevdev.github.io/scad-godot/](https://iliagrigorevdev.github.io/scad-godot/)**

## 📦 Source Code & Game Generator

The source code, scripts, and generation tooling are part of the **[`scad-gltf`](https://github.com/iliagrigorevdev/scad-gltf)** project:

- **Source Scripts:** Ready-to-run Node.js extractor scripts for each game can be found in [`scad-gltf/godot/examples`](https://github.com/iliagrigorevdev/scad-gltf/tree/main/godot/examples).
- **Godot Importer Addon:** The plugin that compiles `.scad` files directly inside Godot is located in [`scad-gltf/godot`](https://github.com/iliagrigorevdev/scad-gltf/tree/main/godot).
- **Generate Your Own Games:** Install `scad-gltf` globally and run the generator CLI:
  ```bash
  npm install -g scad-gltf
  scad-godot "A 3D platformer where you control a rolling sphere collecting crystals"
  ```

---

## 🌐 Browser Requirements

These web builds are exported using Godot 4 HTML5 export:

- A modern desktop or mobile browser with **WebGL 2.0** support (Chrome, Firefox, Edge, Safari).
- WebAssembly (WASM) enabled.
